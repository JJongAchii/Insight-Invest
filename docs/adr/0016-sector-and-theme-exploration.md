# 섹터·테마에서 구성 종목으로 이어지는 시장 분석

2026-09-08. 사용자의 섹터 고도화·테마별 탐색 진행 요청에 따른 구현.

## 화면

기존 다크/라이트 토큰을 유지한다. 캔버스 #0a0f1a, 표면 #101726,
라벤더 #9b7eff, 스카이 #38bdf8, 상승 #34d399, 하락 #fb7185.
제목과 본문은 기존 한국어 sans 계열의 굵기·크기로 구분하고, 숫자는
`--font-data`의 SF Mono/monospace를 사용한다. 새 폰트 다운로드는 필요 없다.

페이지의 특징은 같은 업종의 **수익률과 상승 참여 폭을 나란히 읽는 지도**다.
시총으로 타일 면적을 나누면 작은 업종이 사라지고 기존 세 단계 크기 오해도
이어진다. 동일 면적 타일과 명시적인 시총 비중 수치로 바꾸고, 비교가 필요한
사용자는 정렬 가능한 순위 보기를 선택한다.

```
섹터 / 테마  ·  시장  ·  기간  ·  표시 지표  ·  정산 기준일
지도 / 순위                  선택 그룹 요약 · 시장 대비 추이
구성 종목: 가격·기여 / 수급 / 밸류에이션 · 검색 · 정렬
계산 기준 · 편입 근거 · 출처와 날짜
```

모바일은 세로로 배치하고 선택 시 상세로 이동한다. 필터·선택·정렬은 URL에
기록해 새로고침·브라우저 뒤로가기에 복원된다. 매매 판단·포트폴리오 UI는
이 화면의 중심이 아니다. 관련 문서는 확인 가능한 출처 링크부터 연결한다.

## 계산과 자료

- KRX `adj_close` 가격수익률, 전일 시총으로 일별 그룹 변화를 집계한다.
  배당 재투자 성과나 투자 가능한 전략으로 표현하지 않는다.
- 섹터 과거 구성은 이전 날짜의 최근 분류만 사용한다. 불규칙한 sector
  스냅샷 사이에 신규 상장이 있으면 해당 일자의 stock_master 분류를 그 날에만
  보충한다. 시장 이동은 가격 행의 당시 시장을 따른다.
- 구성 종목은 현행 master를 왼쪽 축으로 유지한다. 가격·수급·펀더멘털이 없는
  종목을 지우거나 0으로 채우지 않는다. 5종목 미만 업종도 탐색할 수 있다.
- 기간은 1/5/21/63 거래일과 전년도 마지막 거래일 종가 기준 YTD다. 종목
  기간수익률은 정확한 양 끝 가격이 필요하며 신규 상장은 산출 불가로 표시한다.
- 기여도는 **당일** 전일 시총 비중 × 당일 가격수익률(%p)이다. 기간 수익률의
  기여도로 오인시키지 않는다. 현재 구성과 과거 업종 구성이 다를 수 있다.
- KOSPI/KOSDAQ 비교는 공식 종합지수 close(1001/2001)를 사용한다. 전체 KR
  테마의 비교 기준은 전일 시총가중 KR 주식 전체의 설명용 가격 변화다.
- 수급은 각 투자자별 선택 기간의 모든 거래일이 확인된 종목만 합산한다.
  종목별 확인 일수 및 그룹별 확인 종목 수를 보여준다. 거래대금은 순매수가 아니다.
- PER/PBR 0·음수는 산출 불가다. 펀더멘털의 실제 관측일을 별도로 표시한다.

테마는 운용사의 공개 자료에서 관련성을 확인한 **일부 대표 종목**을 수동
관리하는 JSON이다. 6개 초기 테마에 출처의 기준일·검토일을 기록한다. ETF의
전체/최신 보유내역·운용비중으로 표현하지 않는다. 중복 편입이 가능하며 테마별
시총을 합산해 시장 전체라고 하지 않는다. 과거 차트는 **현재 대표종목 재구성**이다.
테마 구성은 가격 갱신으로 자동 변경되지 않으며, 변경 시 근거와 검토일을 갱신한다.

## 발행과 검증

EC2의 기존 `build_insights.py` 일일 루프에 `market_groups`를 등록한다.
시장·종류·기간·그룹별 요약 JSON과 상세 JSON을 한 parquet 객체로 발행해
종목 표와 차트가 서로 다른 실행의 숫자를 섞지 않게 한다. Lambda의 목록은
요약 열만, 상세는 단일 그룹 행만 읽는다. 기존 섹터 API는 호환을 위해 유지한다.

단위·기여도 합계·결측·신규 상장·분류 변경·YTD·중복 키·API 필터를 고정된
작은 예제로 검증한다. 실제 데이터는 EC2에서 생성해 행 보존과 출처·기준일을
확인하고, 브라우저에서는 필터/종목 이동/뒤로가기와 모바일·빈 상태·오류를 검증한다.
