# ADR-0022: 운영 원문 편집 점검과 항목별 읽기 요약

- 날짜: 2026-09-11
- 범위: 승인 qws `radar-editorial-feed-v3`, intent `2d79bae58179`
- 목적: 퀀트 투자 아이디어·방법·실증을 읽는 피드. 전략 유효성 심사·자동 백테스트 아님.

## 확인된 문제

9/11 08:42 KST 피드의 core 32개를 다시 점검했다. 공개 원문은 모두 취득했고
31개는 원래 source digest와 동일했다. Robeco 운영모델 글은 현재 본문이 달라
그 변경 사실과 기존 선택 근거를 구분했다. 모든 PDF 전체를 재현 연구로 정독한
것이 아니라 주된 본문·요약에 붙은 인용·조건을 대조한 편집 점검이다.

6개는 일반 AI 업무·제도·산업 배경인데 core로 분류됐다. 나머지 26개 중 RAFI와
Syzygy NLP 한 쌍은 서로 다른 공식 호스트에서 받은 PDF의 바이트 digest까지 같다.
한편 검수는 실제 의미 오류와 잘못된 규칙 판정을 섞어 요약 전체를 숨겼다.
`March`→`3월`, `first-order`→`1차`는 그 자체로 숫자 환각이 아니다. AQR 문서의
법적 `not research` 문구는 이 피드의 콘텐츠 유형 정의가 아니다. 모델이 통과시킨
요약에도 지표명·부분집단 조건 누락과 한계 항목의 잘못된 배치가 있었다.

## 결정

1. source-only 선별 v3는 실제 투자 신호·측정·구성·시장 메커니즘을 설명하는지
   구분한다. 금융기관 독자 대상이라는 이유, AI 사용, 일반 정책은 충분하지 않다.
   짧은 실무 설명·인터뷰·측정 함정에는 논문 형식이나 백테스트를 요구하지 않는다.
2. 이번 점검은 `research_editorial_audit.json`에 명시적 **Codex 편집 결정**으로
   남긴다. 모델 API 영수증을 만들거나 새 프롬프트로 분석했다고 가장하지 않는다.
   ID·URL·출처·본문 hash·제목·parser·scope가 일치할 때만 적용한다. 점검한 좋은
   원문이 새 프롬프트 배포만으로 다시 사라지지 않도록 하고, 변경 원문에는 만료된다.
   추가 문서는 정상 자동 선별로 처리하며 이 파일에 자동 합격을 덧붙이지 않는다.
3. `reading_brief`는 원본 분석과 별도인 읽기 전용 투영이다. 원문/초안/검수
   fingerprint가 유효한 상태에서 독립적으로 supported인 항목만 표시한다.
   숫자·조건 코드 검사와 이번 편집에서 발견한 draft-bound 보류도 적용한다.
   방법 또는 결과가 하나도 남지 않으면 원문만 제공한다. 통과한 다른 문장 때문에
   틀린 문장을 통과시키지 않으며, 분류 항목의 불일치가 모든 번역을 숨기지도 않는다.
4. 일부만 표시하면 UI에 부분 검수와 보류 항목을 표시한다. 원본 초안·기존 rejected
   판정·검사 사유는 그대로 남는다. 표시용 재검산은 추가 LLM 호출이 없다.
5. 동일 PDF 재게시본은 core에서 한 카드만 보인다. 별도 ID와 저장·읽음 기록은
   병합/삭제하지 않는다. 다른 발행처 카드는 읽음·보관함의 전체 기록 또는 exact ID로
   열 수 있다. 중복 판정에는 양쪽 원문 결합 조건과 동일 PDF의 확인 증거가 필요하며
   제목만 비슷한 글은 합치지 않는다. 신규 알림도 대표 카드만 자격을 가진다.
6. 새 선별 프롬프트 실측은 `reading-scope-v1`에서 **자동 모델 판정만** 시험한다.
   동결 편집 결정을 API 품질 통과로 사용하지 않는다. 이 모드는 선별만 호출하며
   기존 qualification 월 $0.50 원장·예약·실패 기록을 그대로 사용한다.

## 검증과 제한

`scripts/verify_research_curation.py`는 운영 스냅샷을 오프라인 투영하고 ID·기존
초안/선별 영수증·최초 available_at·notification origin 보존을 확인한다. 프로덕션
피드 쓰기는 기존 단일 poller만 수행하며 read/save/seen/budget은 이 작업이 직접 쓰지
않는다. 배포 전후 실제 상태 대조를 별도 수행한다.

부분 표시가 전체 요약의 정확성·완전성을 보장하지 않는다. 특히 일부 PDF 글자 간격
손상과 문맥 부족은 남아 있으며, 문제가 있는 문장은 보류한다. 원문은 계속 열 수 있다.
기존 32개 점검을 미래 모든 자료의 품질 보증으로 해석하지 않는다. 자동 검수의 의미적
실패 사례를 유지하고, 새 source selection은 고정 양성/음성 원문으로 확인한다.

모델·주기·production 월 $1.50 + qualification $0.50 한도는 변경하지 않는다.
원문 수집 소스 확장·전략 구현·백테스트는 이번 수정 범위에 넣지 않는다.
