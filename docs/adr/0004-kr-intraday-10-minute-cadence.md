# ADR-0004: KR intraday 10-minute cadence

- Status: Accepted
- Date: 2026-08-26

## Context

KR 장중 시세 폴러는 09:05~15:35 KST에 30분 간격으로 실행됐다. 원천 KRX 데이터가
약 20분 지연되더라도, 수집 간격까지 합치면 화면에서 관측하는 값이 더 오래될 수 있다.
사용자는 비용 증가를 감수하고 시장 흐름을 더 자주 확인할 수 있는 10분 갱신을 선택했다.

## Decision

1. 폴러를 평일 09:05~15:35 KST에 정확히 10분 간격, 하루 40회 실행한다.
2. EventBridge cron의 시간별 minute 제한 때문에 09:05~14:55 룰과
   15:05~15:35 룰로 나눈다. 15:45·15:55에는 호출하지 않는다.
3. 장중 스냅샷의 stale 기준은 기존 40분에서 20분으로 줄인다. 10분 주기 한 번의
   실패에는 직전 값을 유지하고, 20분을 초과하면 `active:false`로 안전하게 강등한다.
4. 수집 데이터는 계속 `app/kr_intraday_*.parquet`에만 기록한다. 정산 가격,
   백테스트, 신호 계산에는 연결하지 않는다.
5. 클라이언트의 5분 refetch는 유지한다. 폴러보다 잦은 화면 요청은 새 스냅샷이
   생겼을 때 최대 5분 안에 반영하기 위한 것이며 KRX 호출을 늘리지 않는다.

## Consequences

폴러 호출은 14회에서 40회, KRX 상위 호출은 ETF 장중 확장(ADR-0005) 후
하루 56회에서 200회로 증가한다.
Lambda와 S3 사용량도 약 2.9배가 되지만 현재 규모에서는 프리 티어 안에 머무를
가능성이 높다. 화면 갱신 주기는 10분이지만 원천 데이터 지연 때문에 실시간 시세로
표현하지 않으며 기존 `지연 시세` 표기를 유지한다.
