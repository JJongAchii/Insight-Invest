# ADR 0026 — 종목 수급 차트의 거래일 연결

- 상태: 채택
- 일자: 2026-09-15

가격 API는 `2026-09-14T00:00:00`, 종목 수급 API는 `2026-09-14` 형태로 같은 거래일을
반환한다. 차트가 두 문자열을 그대로 연결하여 수급이 있어도 막대를 표시하지 않았다.
SK하이닉스의 실제 243거래일 표본에서 문자열 일치 0건, 날짜 일치 243건으로 재현했다.

종목 차트 안에서 두 날짜의 ISO 일자 부분을 연결 키로 사용한다. 거래소의 거래일이므로
UTC 변환으로 날짜를 이동시키지 않는다. 가격 API와 가격·수익률 계산은 유지한다.
수급 결측값은 `null`로 보존하며, 관측된 0과 구별한다.

외국인·기관·함께 보기에는 최근 관측 금액, 단위, 실제 표시 구간을 안내한다.
수급 요청의 로딩·오류·미제공을 구별하고 오류에는 다시 시도 동작을 제공한다.
기간 전환에는 해당 요청의 `currentData`만 연결한다.

실제 가격·수급 API 응답을 브라우저에서 재생하여 날짜 연결과 막대 표시를 검증한다.
오류 복구·기간 선택·결측/0·모바일·양쪽 테마·미국 종목의 가격 화면도 확인한다.
