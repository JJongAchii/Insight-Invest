# ADR 0018 — 장중 섹터 구성종목 탐색

- 상태: 채택
- 일자: 2026-09-09

장중 히트맵은 요약만 표시해 정산 섹터 화면과 달리 구성종목을 열 수 없었다.
섹터 선택 시 가격·전일 대비 등락률·누적 거래대금과 시장을 확인하고 종목 상세로 이동한다.

`GET /intraday/market?sector=…`가 요약과 선택 섹터의 전체 종목을 같은 응답으로 반환한다.
기존 snapshot의 `sector`를 그대로 필터한다. 급등락 상위 종목의 시총·거래대금 제한을
적용하지 않으며 정산 자료나 테마 대표종목을 섞지 않는다. 거래정지·가격 미형성 종목은
생산자의 기존 snapshot 제외 기준을 따르므로 목록을 상장종목 전체로 표현하지 않는다.

주식 latest의 정확한 관측 시각까지 timeline을 제한하고 같은 poll의 index/breadth/sector가
없으면 `inconsistent`로 안내한다. 같은 날짜의 서로 다른 poll을 섞는 PUT 경계도 차단한다.
유효시간 정책은 유지한다. 선택하지 않으면 구성종목 payload를 추가하지 않는다.
앱 meta는 브라우저에서 상세 링크만 제공하고 미등록 종목은 검색으로 연결한다.
따라서 meta 부재가 snapshot 구성종목이나 집계의 행을 제거하지 않는다.

URL `live_sector`로 선택을 보존한다. RTK Query의 인자별 응답으로 개요와 종목이 함께
갱신되며 새 선택을 기다릴 때 이전 섹터의 구성종목은 숨긴다. 방문했던 선택도 재조회한다.
검색·정렬·25종목 페이지는 목록 내부 상태이며 섹터를 변경하면 초기화된다.

## 화면 방향

- 색상: 기존 canvas #0a0f1a, surface #101726, lavender #9b7eff,
  sky #38bdf8, gain #34d399, loss #fb7185와 light 모드 토큰을 유지한다.
- 글꼴: 기존 한국어 sans의 중량·크기로 섹터명/설명을 구분하고 `.num`의 SF Mono를 숫자에 쓴다.
- 배치: 히트맵 → 선택 섹터의 구성종목 → 기존 흐름 차트. 모바일은 표 대신 종목별 행 카드.
- 특징: 섹터 등락률 색과 선택 테두리가 아래 종목 분석으로 연결된다. 타일의 종목 수·거래대금은
  실제 집계 의미를 전달한다. 새로운 장식이나 별도 요약 카드 없이 탐색에 집중한다.
- 타일은 기본 button으로 키보드 선택 가능하며, 선택 뒤 목록 제목에 초점을 옮기고 모바일에서
  목록으로 스크롤한다. 로딩 완료 뒤 목록 길이가 늘어나는 경우도 맞춘다.
  자동 갱신은 초점을 이동하지 않는다. 지도의 높이를 제한하고 목록에 `섹터 다시 선택`을 둔다.

## 검증

API: 전체 구성/시장 혼합/결측/미분류/빈 선택/소형주/정합성/유효시간.
브라우저: 클릭·키보드·검색·정렬·페이지·직접 링크·뒤로가기·빠른 전환·오류·320/390px.
