# ADR 0025 — 검토 알림 안에서 읽는 발표 수치

- 상태: 채택
- 일자: 2026-09-15

검토함·일정에서 상세보기 없이 경제지표·기업실적의 핵심 수치를 비교한다. 기존 카드와
개인 알림 동작은 유지하고 제목·설명 다음에 작은 수치 표를 넣는다. 상세보기는 원문과
추가 해석을 읽는 보조 동작이다.

향후 일정에 최근 결과가 묻히지 않도록 `발표 결과` 필터는 최근 7일 중 실제 수치가
확인된 항목만 모은다. 0도 유효한 발표값으로 포함하고, 발표 대기 항목은 전체에서 확인한다.

## 화면 방향

기존 canvas #0a0f1a, surface #101726, text #e5e7eb, lavender #9b7eff,
sky #38bdf8와 light 토큰을 유지한다. 제목·설명은 기존 Inter/한국어 sans,
수치는 SF Mono 계열 tabular 숫자를 쓴다. 큰 통계 카드 대신 발표값 열을 강조하는
비교 표를 선택한다. 모바일은 각 지표의 2열 묶음으로 읽으며 가로 스크롤을 요구하지 않는다.

`제목·일정 → 설명 → 지표명·관측기간 / 발표값·예상치·이전값·차이 → 출처 → 상세보기`

경제지표의 상승·하락에 투자 호재·악재 색상을 부여하지 않는다. 발표값 없는 미래 일정,
결과 반영 대기, 수집 실패, 예상치 미제공을 구별한다. 새로운 애니메이션은 추가하지 않는다.

## 데이터 계약

외부 이벤트 parquet에 JSON 문자열 `result_summary`를 추가하고 API에서는 객체로 반환한다.
기존 파일은 필드가 없어도 읽는다. 이벤트 식별자·읽음·숨김·푸시 정책은 유지한다.

FRED는 기존 8개 발표 분류의 대표 지표를 조회한다. 발표일과 관측기간은 다른 필드다.
과거 발표는 해당 날짜의 FRED vintage가 확인될 때만 그 날짜 시점의 값을 발표값으로
표시한다. 이후 개정값을 이전 발표에 덮어 붙이지 않는다. 미래 일정은 최신 관측값을
최근값 참고로 제공하고 발표값은 비워 둔다. FRED에서 새 값이 확인되지 않으면 반영 대기다.
이전 기간 값도 같은 vintage 기준이므로 개정될 수 있으며 최초 발표치 복원과 구별한다.

기존 수집 시작일을 오늘에서 최근 7일로 확장해 API의 기존 7일 결과 창을 채운다.
예상치는 FRED 계약에 없으므로 임의 예측을 만들지 않는다. 기업실적은 기존 Earnings Hub의
공식 수치 보완 규칙을 공유한다. 비교 기준이 다른 공식 EPS와 컨센서스의 차이는 계산하지 않는다.
공시·정책 일정처럼 수치 계약이 없는 이벤트는 원문 안내를 유지한다.

## 검증

발표일 일치·미래값 차단·부분 실패·결측·0·개정 시점·공식 EPS 비교 보류를 검증하고,
배치 → parquet → API → 검토 카드 경로와 모바일·양쪽 테마·기존 알림 동작을 확인한다.

- [FRED vintage dates](https://fred.stlouisfed.org/docs/api/fred/series_vintagedates.html)
- [FRED release dates](https://fred.stlouisfed.org/docs/api/fred/release_dates.html)
