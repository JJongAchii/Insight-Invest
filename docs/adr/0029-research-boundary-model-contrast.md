# ADR-0029: 실패 보존 후 판정 모델만 바꾸는 제한 진단

2026-09-14. qws intent `2d79bae58179` 유지. 사용자의 오분류 수리·실제 검증 요청과
검증 우선 예산 승인 범위에서, 운영 교체가 아닌 원인 분리 진단을 한다.
현재 mini/v3 실패는 ADR-0027과 qws `EXPLANATION-CARD-HOLD-20260914.md`에 고정했다.

## 가설과 변경 변수

SaaS는 차단했으나 ETF 상품 소개는 다시 통과했다. 명시적 제외 설명이 프롬프트에
있어도 모델이 실제 기여의 구체성을 과하게 인정했다. 같은 원문·문장 분할·v3 요청을
다른 모델에 주면 이 오류가 유지되는지 확인한다. 모델 크기만의 인과 효과를 주장하지
않는다. 세대·학습 차이와 단일 응답 변동성이 함께 포함된 모델 간 관측 비교다.

진단 모델은 `gpt-5.4-2026-03-05`로 하나만 고정한다. [공식 모델 문서](https://developers.openai.com/api/docs/models/gpt-5.4)에서
Responses, strict structured output, medium 및 snapshot을 확인했다. 단가는 입력
$2.50/출력 $15 per 1M tokens이며 기존 보수적 바이트 예약 계산에 이 단가를 적용한다.
특정 계정에서 접근 가능한지는 실제 요청 전까지 보장하지 않는다. 접근/형식/한도 오류
시 대체 모델로 자동 전환하지 않는다. 단가는 비교 비용이지 품질 보증이 아니다.

v7 첫 선별은 GPT-5 mini의 보존 영수증을 그대로 재사용하며 없거나 입력이 다르면
호출 전에 중단한다. v3 SYSTEM·SCHEMA, source-only 입력, medium, 4096 출력 한도,
24000자, 파서·기대값·원문 hash·qdata commit 모두 유지한다. 요약·대조는 실행하지 않는다.
모델과 단가는 격리 qualifier 프로세스 안에서만 적용하고 종료/예외 시 복원한다.
운영 모듈/환경 기본 모델은 그대로 GPT-5 mini다. 새로운 fallback·유료 단계는 없다.

## 사전 고정 대조와 정지

1. `reading-gate-products-v1`: 기존 AQR Academic Alpha/CFM Hidden Beta는 core,
   Robeco ETF는 context 또는 held. 세 원문, 신규 boundary 최대 3회.
2. 첫 묶음의 세 라우팅과 실제 의미를 확인한 경우에만 `reading-gate-boundaries-v1`:
   AQR Warming World는 core, SaaS와 KCMI 토큰은 context 또는 held. 신규 boundary
   최대 2회(KCMI는 보존 첫 선별 context). 원문당 동일 fingerprint 재생성 금지.
3. 분류뿐 아니라 설명 statement와 첨부 인용의 지지 범위도 따로 기록한다.
   잘못된 승격, 좋은 연구 누락, 근거 불충분은 각각 보존한다. 형식 검사의 성공을
   의미 인수로 바꾸지 않는다. 실패 시 추가 모델/프롬프트를 자동 연속 시험하지 않는다.

총 새 호출 최대 5회, 현재 격리 월 $1 안에서만 실행한다. 시작 원장 $0.61030520,
잔여 $0.38969480. 매 요청 최악 예약이 잔여를 넘으면 중단하며 원장/실패 예약을
지우거나 입력·출력을 줄이지 않는다. 운영 $1과 합쳐 기존 월 $2 이내다.

이미 사람이 읽고 수리에 사용한 표본의 진단이다. holdout 정확도·일반화·운영 승격
검증으로 부르지 않는다. 특정 문서마다 다른 모델의 유리한 결과를 골라 합치지 않는다.
두 묶음이 맞더라도 나머지 표본·독립적인 새 글·근거/요약·UI 인수 전 배포하지 않는다.
결과는 `diagnostic_only`이며 발행 도구에서 일괄 거부한다. PR51 draft/HOLD 유지.

## 실제 대조 결과 — 운영 교체 근거 없음

앱 `3d12fd8df36f042950b1a87a0ba1a58840ab8913`, 실행
[34819606532](https://github.com/JJongAchii/Insight-Invest/actions/runs/34819606532).
첫 products 묶음에서 AQR Academic Alpha/CFM Hidden Beta는 core를 유지했지만,
Robeco ETF도 여전히 core였다. mini/v3 기준과 동일하게 세 라우팅 중 두 개만 맞았다.
가장 큰 모델을 찾는 탐색으로 확대하지 않고 여기서 중단했으며, 둘째 boundaries
묶음은 실행하지 않았다. 더 강한 모델에서도 동일 오류가 관측된 것이지, 모든 모델이
실패한다거나 모델 능력이 전혀 무관하다는 증명은 아니다.

ETF의 work는 수익·위험·지속가능성을 함께 고려한다는 설명이고 result는 벤치마크
역할·위험관리 목표였다. 판단은 고수준 설명이어도 실제 구성 방법이라고 인정했다.
원문이 구체적인 투자 판단을 가르치는지와 상품의 운용 방향을 설명하는지를 구분하지
못하는 문제가 남았다. AQR의 근거 선택은 더 구체적이었지만 ETF/CFM 카드 일부는
여전히 첨부 인용보다 넓은 설명을 포함한다. 카드가 존재하면 의미가 검증된 것이 아니다.

v3 요청 설정과 라우팅을 대조했다. 첫 선별/요약 재생성 0회, 새 boundary 3회,
