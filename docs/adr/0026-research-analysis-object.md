# ADR-0026: 설명의 구체성과 분석 대상을 분리

- 날짜: 2026-09-14.
- 사용자 승인: SaaS 산업 전망 오분류를 분석 대상 구분으로 수리하자는 보고에 대한
  `응 진행해`. qws intent `2d79bae58179` 유지.
- 상태: v2 실제 원문 인수 실패, 운영 배포 보류.

## 범위

ADR-0025 v1 실패와 기존 13편의 기대값·본문 hash를 보존한다. 첫 선별 v7, 모델
GPT-5 mini, medium, 토큰 한도, 요약·대조·라우터·호출 단계 수는 바꾸지 않는다.
새 유료 단계나 발행처/제목 차단 목록은 없다. 기존 v1 검수는 v2로 성공 처리하지 않는다.

두 번째 요청 `reading-boundary-v2-analysis-object`에서 설명의 **분석 대상**을
원문 근거와 함께 먼저 고른다. 투자 규칙·측정 또는 시장 가격·위험의 역학은 후보지만,
기업 매출·제품 경쟁·사업 전망·상품 도입·기관 제도는 배경이다. 투자자 대상 문서나
가격/DCF를 언급하는 구체적 사업 설명이라는 사실만으로 퀀트 핵심이 되지 않는다.
시장 신용/자금조달 피드백과 기업 경쟁 전망은 구분하고 수식·백테스트를 필수로 하지 않는다.

그다음 contribution verdict를 낸다. 코드도 비투자 대상+substantive 모순을 context로
반영하되 모델 원 응답을 보존한다. 대상 불명은 uncertain, 대상 누락/알 수 없는 값·
원문 근거 오류·이전 캐시는 pending이다. 첫 core와 context/uncertain이 만나면 held로
발견함에 남고, source-only 검수에 첫 판단/선별 passage/AI 요약은 입력하지 않는다.

## 인수와 비용

우선 같은 고정 SaaS 음성과 AQR 기후 지표 양성을 동시에 확인한다. 둘 중 한쪽만
통과하면 완료로 보고하지 않는다. 그 다음 ETF/실무 글을 포함한 기존 13편을 같은
정책으로 검사한다. 첫 선별 캐시는 재사용하고, v1 검수 결과를 새 검수 대신 쓰지 않는다.
의미 인수 실패 시 영수증을 보존하고 추가 유료 버전을 반복하지 않는다.

시작 검증 원장 $0.57214320/$0.60. 운영 $1.40와 월 합계 $2는 그대로다.
13편 전체 재검증 비용이 부족할 가능성이 있어 **월 합계 $2 안에서 운영 $1.30,
검증 $0.70 재배분을 비동기 질문으로 요청**했다. 명시 응답 전에는 한도를 바꾸지
않고 기존 예약 한도만 사용한다. 운영 원장 사용액을 확인하지 않은 재배분도 금지한다.
예산 부족 시 미검증 자료·범위를 그대로 표시하며 검사 통과나 배포 완료를 주장하지 않는다.

공식 문서의 schema 준수는 의미 정확도 보장이 아니다. 실제 원문 인수는 별개다.
[Structured Outputs](https://developers.openai.com/api/docs/guides/structured-outputs),
[GPT-5 mini](https://developers.openai.com/api/docs/models/gpt-5-mini).

## 실제 원문 결과 — v2도 같은 SaaS 경계를 통과시키지 못함

앱 `ce4242c1d4b8e87249660359435287f6ab86a342`, qdata
`050433aad2f06b9cf58a034cf1c3b4952583fcd7`의
[격리 실행 34798293303](https://github.com/JJongAchii/Insight-Invest/actions/runs/34798293303)은
`needs_diagnosis` / failure로 끝났다. 고정 3편의 공식 원문을 다시 가져와 기존
본문 digest와 대조했고, v7 선별 캐시를 재사용한 뒤 필요한 v2 검수 2회만 호출했다.

| 고정 원문 | v2 자동 경로 | 기대값 대조 |
| --- | --- | --- |
| AQR Investing in a Warming World | core | 일치: 포트폴리오 탄소 지표 측정·분해 |
| KCMI 토큰증권 인프라 | context | 일치: 기존 v7 선별 결과, v2 호출 불필요 |
| Syzygy The Impact of AI on SaaS | core | **불일치: 산업·사업 전망을 재차 핵심으로 오분류** |

SaaS 검수는 `analysis_object=investment_rule_or_measurement`와
`verdict=substantive`를 함께 반환했다. 분석 대상 근거는 기간별 AI 위험 프레임워크를
제공한다는 문장이었고, 판단 이유는 좌석 라이선스 감소가 반복 매출·가치평가에 미치는
영향이었다. 원문에 있는 인용이고 형식도 유효하지만, 승인된 편집 경계의 투자 측정
방법을 입증하지 않는다. 코드의 비투자 대상 veto는 **모델이 분석 대상부터 잘못
고르면 작동하지 않는다**. 분석 대상 필드를 추가하는 것만으로 실제 의미 오류를
수리했다는 가설은 이 사례에서 기각됐다. PDF 분절이 보이지만 그 영향은 확인하지
않았으며 원인으로 단정하지 않는다.

이번 v2 인수는 3편 중 2편 일치다. v1 결과를 v2 결과와 합쳐 13편 통과 또는 일반화
성공으로 보고하지 않는다. v2 전체 표본 인수와 운영 이관은 미완료다.

새 API 비용 $0.009161, 격리 원장 $0.57214320 → $0.58130420/$0.60,
실패·미정산 예약 차액 0. 재배분 질문에 명시 승인이 없으므로 운영 $1.40/검증 $0.60과
월 합계 $2를 유지했다. 의미 인수 실패 후 추가 유료 버전·호출을 실행하지 않았다.

연구·알림 회귀 테스트 290개, Ruff, Next.js production build는 통과했다. 이들은
기계적 계약 검증이며 위 원문 의미 인수를 대신하지 않는다. 이번에는 새 UI 변경이나
운영 사용자 상태 이관을 수행하지 않았다. PR #51은 draft/HOLD, main merge·운영
캐시 이관·배포는 미실행이다. 이전 실패 기록과 고정 기대값·본문 hash를 보존한다.

다음 판단에 필요한 것은 또 하나의 enum 이름이나 이 문서 제목 차단이 아니라,
이 경계를 어떤 검증 가능한 근거로 구분할지에 대한 별도 수리안이다. 그 수리안 없이
프롬프트·모델·예산을 바꿔 재시도하거나 이번 버전을 운영에 올리지 않는다.
