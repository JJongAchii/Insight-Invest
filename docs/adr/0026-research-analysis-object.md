# ADR-0026: 설명의 구체성과 분석 대상을 분리

- 날짜: 2026-09-14.
- 사용자 승인: SaaS 산업 전망 오분류를 분석 대상 구분으로 수리하자는 보고에 대한
  `응 진행해`. qws intent `2d79bae58179` 유지.
- 상태: 구현·인수 진행 중, 운영 배포 전.

## 범위

ADR-0025 v1 실패와 기존 13편의 기대값·본문 hash를 보존한다. 첫 선별 v7, 모델
GPT-5 mini, medium, 토큰 한도, 요약·대조·라우터·호출 단계 수는 바꾸지 않는다.
새 유료 단계나 발행처/제목 차단 목록은 없다. 기존 v1 검수는 v2로 성공 처리하지 않는다.

두 번째 요청 `reading-boundary-v2-analysis-object`에서 설명의 **분석 대상**을
원문 근거와 함께 먼저 고른다. 투자 규칙·측정 또는 시장 가격·위험의 역학은 후보지만,
기업 매출·제품 경쟁·사업 전망·상품 도입·기관 제도는 배경이다. 투자자 대상 문서나
가격/DCF를 언급하는 구체적 사업 설명이라는 사실만으로 퀀트 핵심이 되지 않는다.
시장 신용/자금조달 피드백과 기업 경쟁 전망은 구분하고 수식·백테스트를 필수로 하지 않는다.

그다음 contribution verdict를 낸다. 코드도 비투자 대상+substantive 모순을 context로
반영하되 모델 원 응답을 보존한다. 대상 불명은 uncertain, 대상 누락/알 수 없는 값·
원문 근거 오류·이전 캐시는 pending이다. 첫 core와 context/uncertain이 만나면 held로
발견함에 남고, source-only 검수에 첫 판단/선별 passage/AI 요약은 입력하지 않는다.

## 인수와 비용

우선 같은 고정 SaaS 음성과 AQR 기후 지표 양성을 동시에 확인한다. 둘 중 한쪽만
통과하면 완료로 보고하지 않는다. 그 다음 ETF/실무 글을 포함한 기존 13편을 같은
정책으로 검사한다. 첫 선별 캐시는 재사용하고, v1 검수 결과를 새 검수 대신 쓰지 않는다.
의미 인수 실패 시 영수증을 보존하고 추가 유료 버전을 반복하지 않는다.

시작 검증 원장 $0.57214320/$0.60. 운영 $1.40와 월 합계 $2는 그대로다.
13편 전체 재검증 비용이 부족할 가능성이 있어 **월 합계 $2 안에서 운영 $1.30,
검증 $0.70 재배분을 비동기 질문으로 요청**했다. 명시 응답 전에는 한도를 바꾸지
않고 기존 예약 한도만 사용한다. 운영 원장 사용액을 확인하지 않은 재배분도 금지한다.
예산 부족 시 미검증 자료·범위를 그대로 표시하며 검사 통과나 배포 완료를 주장하지 않는다.
