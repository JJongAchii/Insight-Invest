# ADR-0021: 원문 선별과 한국어 요약 검수를 분리한다

2026-09-10. 승인된 원문 읽기 피드 목표 안의 구현 수정.

## 문제

ADR-0019의 요약 릴리스 스위치가 원문 core 노출과 신규 알림까지 막았다.
이는 원문을 모아 읽고 싶은 사용자 목적에 맞지 않는다. 또한 생성된 요약을
보고 분류하면 생성기의 시장 전망 오분류를 검수기가 그대로 합리화할 수 있다.

## 결정

1. 기존 단일 writer ResearchPoller에 source-only 선별 단계를 먼저 둔다.
   원문만 보고 주된 목적, 정량 투자 관련성, 다른 상황에도 적용해 볼 수 있는
   방법·메커니즘·관찰의 근거 문장을 추출한다. 기관 명성과 키워드만으로 승격하지 않는다.
2. 선별 receipt는 원문 digest·제목·parser·범위·분류 버전에 묶인다.
   유효한 core 선별이면 요약 pending/rejected/off 여부와 관계없이 핵심 원문을 노출한다.
   명세 없는 AI 활용 소개·현재 시장 포지셔닝은 context로 보존하고 요약 비용을 쓰지 않는다.
3. 선택된 원문만 기존 한국어 생성 → 별도 원문 대조로 보낸다. 초안과 검수 이력은 보존한다.
   요약 노출은 여전히 현재 버전의 검수 accepted만 허용한다. 과학적 검증 판정이 아니다.
4. 원문 신규성은 producer notification_origin 계약을 그대로 유지한다.
   과거 편집/요약/파서 수정은 신규 발행이 아니다. 무증명 pending은 삭제하지 않고 격리한다.
5. 세 단계 모두 GPT-5 mini/medium, 기존 월 $1.50 운영·$0.50 qualification 원장을 공유한다.
   호출 전에 예약하고, 한 회차에 최대 한 유료 단계, 캐시 재사용, 실패 예약·재시도 상한을 유지한다.
6. 숫자는 해당 항목 인용에서 추적 가능해야 한다. 깨진 PDF 소수점은 복원하지 않고
   인용 불가 처리한다. 번역/숫자 코드 가드는 보조 수단이며 의미 정확성의 증명은 아니다.
7. v1/v7 실패 fixture는 바꾸지 않는다. parser 수정은 reading-value-v2로 명시 분리한다.

## 검증

오프라인 검증: 요약 off/rejected/budget failure 중 원문 유지, receipt 만료,
시장 전망에서 후속 API 호출 0회, 변경 전 read/save/seen 보존, 기존 신규성·pending 격리 회귀.
실제 API: 고정 원문 AQR/RAFI/Robeco로 분류와 한국어 문장 각각 직접 검토한다.
API 계약 통과와 실제 의미 품질 인수를 같은 것으로 보고하지 않는다.

첫 실제 v9 테스트(34439688549)에서 RAFI 초안이 항목 밖의 사실을 끌어왔고
AQR 선별 근거 4문장 합계가 길이 제한을 넘었다. 실패 결과는 그대로 남긴다.
후속 수정은 선별기가 항목별 자립적인 근거 한 문장만 먼저 고르게 하고, 생성기는
그 선택된 근거만 받는다. 생성·검수 JSON schema의 인용 ID도 항목별 허용 목록에
고정한다. 선택된 근거가 달라지면 생성 cache도 만료된다. 이는 검수 기준 완화가 아니다.

실제 v10/v5에서는 AQR의 자유서술 AI 메모가 서로 다른 지표의 조건을 섞었고
`active carbon exposure`를 `활성 탄소 노출`로 옮겼다. v11/v6는 근거 없는 메모를
아예 생성·표시하지 않고, 용어 지침과 알려진 오역 가드를 추가한다.
Actions 34441069534의 동일 고정 원문 재시험에서 AQR·RAFI는 선별 core 및 요약
accepted, Robeco는 시장 전망 context였다. 두 요약을 직접 읽어 항목별 인용과
대조했고, 1440px/390px 실제 화면의 읽음·저장·검색 회귀를 통과했다. 이 세 표본의
의미 검토를 전체 출처/향후 모든 글에 대한 정확도 보장으로 확대하지 않는다.

운영 인계는 `scripts/publish_research_qualification.py`로 정확한 report SHA를 입력해
원문을 재취득·재검증한 뒤 selection/cache/reviews 객체만 조건부 추가한다.
기존 객체가 다르면 덮어쓰지 않는다. 기본은 dry-run이며 feed·사용자 서재·seen·pending·
budget은 쓰기 대상이 아니다. 최종 피드 반영은 단일 ResearchPoller가 담당한다.
유료 단계 한도/월 예산 때문에 뒤쪽의 이미 검수된 캐시 복구가 막히지 않게 한다.
본문 hash에 영향을 주는 qdata도 Docker에서 qualification과 같은 exact commit으로 고정한다.

추가 고정 표본 `reading-diversity-v1`은 D. E. Shaw의 포트폴리오 최적화, CFM의
딥 매수/베타 연구, Syzygy 회사 소개다. 원문 분류는 core/core/context였지만,
CFM 초안은 지표명 없는 수치를, D. E. Shaw 초안은 빠진 설계 전제를 포함했다.
모델 검수도 이를 놓쳤다. v8 검수와 명시적인 코드 가드로 두 요약을 보류한다.
이는 원문 가치의 기각이 아니라 현재 한국어 초안의 보류이며 자동 재생성을 반복하지 않는다.

코드 가드는 모델 검수와 버전을 분리한다. 전제 보존 검사는 제목이나 비어 있는 메모가
아닌 본문 point에만 적용한다. `verify_research_review.py --recheck-code-guards`는
같은 모델·프롬프트·원문·초안·실제 인용 ID를 확인하고 실제 모델 판정을 그대로 보존한 채
코드 가드와 최종 판정만 재계산한다. 원래 API artifact를 덮어쓰지 않고 그 SHA와
previous_review_fingerprint를 연결하며 LLM 호출은 0회다. 검수를 완화해 보류를
풀기 위한 경로가 아니다. 이번 재계산 뒤에도 CFM/D. E. Shaw는 각각 해당 point로 보류다.

최종 실제 API 원본: 34444184753(다양성), 34444185729(AQR/RAFI/Robeco).
코드 재검산 뒤 핵심 원문 4개, 표시 가능한 한국어 요약 2개, 보류 요약 2개,
시장·배경 2개다. 이는 초기 제한 운영 표본이며 광범위한 20–30편 품질 인수는 남아 있다.
기존 실패와 예약을 포함한 qualification 누적은 $0.43863545 / $0.50이다.

## 비목표
