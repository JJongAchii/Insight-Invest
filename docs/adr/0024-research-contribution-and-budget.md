# ADR-0024: 읽을 수 있는 연구 기여와 상품 소개의 구분

- 날짜: 2026-09-11.
- 승인 범위: qws `radar-editorial-feed-v3`, intent `2d79bae58179` 변경 없음.
- 사용자 승인: 월 총 $2 유지, 운영 $1.40·검증 $0.60 재배분 및 공통 분류 기준
  보완 제안에 대한 `응`.

## 확인된 공통 원인

ADR-0023의 주제·형식 분리는 기존 정책/AI 업무 표본을 통과했지만 ETF 소개와
생물다양성 상품화 글을 투자 방법으로 골랐다. 금융 주제와 설명의 실제 내용·깊이는
같지 않다. 방법 이름, 목표 수익·위험·지속가능성, 상품 혜택을 언급했다는 이유만으로
구체적인 연구 기여가 있다고 볼 수 없다. 명시적인 원문 편집 보정과 자동 모델의
분류 성공은 계속 분리한다. 기존 실패와 예산 영수증은 보존한다.

## 승인된 예산 재배분

production $1.50 → $1.40, qualification $0.50 → $0.60이며 합계는 월 $2다.
원장의 사용액·실패 예약·캐시를 삭제하거나 초기화하지 않는다. 먼저 예산 변경만
main에 반영해 운영 함수를 갱신한다. qualification workflow는 운영 함수에서
해당 한도 하나만 조회하고 $1.40을 확인한 뒤 실행하므로 이전 운영 한도와 새 시험
한도를 동시에 사용하지 않는다. 키·전체 환경변수를 출력하지 않는다.

모델 GPT-5 mini, medium 추론, 입력/출력 토큰 상한, 유료 단계 수, 수집 주기는
바꾸지 않는다. 이 한도는 앱의 UTC 월별 예약 한도이며 계정 전체 청구 상한은 아니다.

## 구현·인수 경계

공통 분류 수정은 별도 커밋으로 한다. 이미 확인한 상품/상품화 음성 원문과 실제
투자 원리·측정·실증을 설명하는 양성 원문을 호출 전에 고정하고 자동 `model_state`만
검사한다. 단순 문구 강화나 제목·발행처 차단 목록으로 인수를 대신하지 않는다.
기존 주제·형식 분리, 원문 hash, 자료 기록·서재·확인 상태·과거 알림 억제를 보존한다.

공식 Structured Outputs의 schema 준수는 의미 정확도 보장이 아니므로 실제 공개
원문 검증이 필요하다. 현재 모델·단가는 유지한다.
[응답 형식](https://developers.openai.com/api/docs/guides/structured-outputs),
[GPT-5 mini](https://developers.openai.com/api/docs/models/gpt-5-mini).

새 소스 확대·전략 구현·백테스트·모델 교체는 이번 변경에 포함하지 않는다.

## 2026-09-13: v6 구현·고정 회귀 표본

`reading-selection-v6-demonstrated-contribution`은 기존 원문 선별 호출 안에
`contribution_type`을 추가한다. 구체적인 규칙/측정, 투자 원리, 자료·설계가 있는
실증 설명 중 하나와 투자 주제·원문 근거가 함께 있어야 자동 core다.
개념·목표·효용 소개(`overview_or_claim`)와 비투자 주제(`none`)는 context다.
새 항목 누락·알 수 없는 값·이전 prompt fingerprint는 pending이며 모델의
모순된 원 응답은 진단을 위해 보존한다. 독립 편집 보정은 그대로 별도 표시한다.

인수 전에 원문 URL/본문 hash/기대 분류를 고정한 13편을 사용한다:

- core 7: AQR Academic Alpha·Warming World, D. E. Shaw Machine Teaching,
  CFM Hidden Beta, Robeco Systematic Credit, RAFI NLP, Verdad Credit Reflexivity.
- context 6: Robeco ETF 소개·생물다양성 상품화·AI 연구 업무, KCMI 퇴직연금 개편·
  토큰증권 인프라, Syzygy SaaS 산업 전망.

자료·신호·측정·원리의 설명을 요구하되 논문 형식·수식·완전한 재현 명세를 요구하지
않는다. 기후 연구와 AI 신호 연구 양성을 포함하여 주제 자체를 차단하지 않는지도
확인한다. 기관당 개별 예외를 추가하지 않는다. 기존 고정 표본의 실패 기대값을
수정하지 않았으며, 6개의 최대 3-source 묶음은 같은 입력의 현재 캐시를 공유한다.
기존 편집 감사에서 고른 자료이므로 미관측 holdout 정확도라고 주장할 수 없다.

전체 자동 회귀와 계약 테스트가 통과한 뒤에만 v6를 운영 배포한다. 원문 변경,
예산 부족 또는 의미 분류 실패 시 해당 결과를 기록하고 배포를 보류한다.

## v6 실패와 한 차례의 구조적 수정

v6는 실제 6개 호출 중 ETF/AQR/CFM/D. E. Shaw/KCMI를 맞췄지만 생물다양성
상품화 글을 다시 core로 분류했다(Actions 34759185877, 34759276335).
모델은 국소적인 자연 영향과 표준 금융상품의 차이를 측정 방법으로 오인했다.
그래서 v6 운영 배포와 나머지 v6 유료 호출은 보류했다. 실패의 원문, 기대 분류,
6개 영수증 및 사용액은 유지한다.

`reading-selection-v7-evidence-first-purpose`는 같은 호출 안에서 **본문의 주된
질문/결론을 나타내는 원문 문장을 먼저 선택**하고 목적을 분류한다. 뒤에 나온
금융 용어·기여 분류가 주된 상품 채택/사업 전망/제도 개편 목적을 뒤집을 수 없다.
측정이 어렵다는 문제 제기와, 지표의 계산·분해·측정 결과를 설명하는 것은 구분한다.
core는 투자 분석 목적과 그 문장 근거를 추가로 요구한다. 목적이 다른 모순 응답도
원 영수증에 남기되 context로 내린다. 입력·모델·토큰 상한·호출 단계 수는 같다.

13편의 본문 hash와 core/context 기대 분류는 바꾸지 않는다. v7를 한 차례 검사하며
또 의미 실패가 나오면 추가 버전 반복이나 예산 증액 없이 결과를 보고한다.

v7 실제 호출에서도 고정 경계를 모두 통과하지 못했다(Actions 34759615806,
34759730256). 생물다양성 글은 context로 내려갔지만 ETF 소개가 다시
investment_analysis/rule_or_measurement/core로 올라갔다. AQR·CFM·D. E. Shaw
양성과 KCMI 정책 음성은 유지됐다. v7 추가 유료 호출과 운영 배포는 중단했다.
고정 13편 중 각 버전에서 6편만 실행했으며 나머지 7편은 미검증이다.
현재 운영은 PR #50의 예산 변경과 이전 v5 분류를 유지한다. PR #51은 draft이며
선별 캐시의 운영 이관도 실행하지 않았다. 이전 수동 ETF 보정으로 성공을 꾸미지 않는다.

확인한 것은 현재 단일 모델 선별 설계의 불안정성이며, 모든 모델이 불가능하다는
증거는 아니다. 다음 방향은 별도 승인 후 애매한 후보의 원문을 독립적으로 검수하고
불일치를 보류하는 구조를 검토하는 것이다. 새 모델/유료 단계는 이번에 추가하지 않았다.
