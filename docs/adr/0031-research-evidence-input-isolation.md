## Two repairs, separately observable

1. Boundary v5 receives ONLY the proposed literal insight/method passages and the
   first reader's literal purpose passage. No title, publisher or surrounding body
   is sent. The first reader still sees the bounded full body and owns primary-topic
   selection. The checker cannot use unseen context to repair an insufficient quote.
   Its object citation must be an actually visible ID, not merely a valid ID elsewhere
   in the original. Receipts distinguish source input length from model-read length.
2. The selector must choose the disclosed analytic relation rather than a generic
   ranking-engine description. A generic universe/entity or undefined attractiveness
   score is not a measured input. A qualitative credit-risk comparison, sensitivity
   exercise or methodological pitfall is enough; full reproducibility is not required.

This does not add a paid stage, replace the model, change source admission scope or
claim deterministic semantic truth. It removes a concrete evidence-context leak.
The budget reservation is calculated on the actual reduced payload.
