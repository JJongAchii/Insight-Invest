# 장중 탭 선택과 데이터 가용성 분리

2026-09-09. 사용자가 장중 스냅샷 버튼을 누를 수 없다고 제보했다.

`disabled={!intraday?.active}` 때문에 최초 조회·요청 오류·비활성 응답에서
버튼이 막혔다. 직접 `tab=intraday`로 열어도 `showLive`가 데이터의 `active`에
묶여 있어 정산 화면으로 바뀌었다. 기존 응답 `{active: false}`는 자료 부재,
스테일, 파일 간 불일치와 조립 오류를 구분하지 못했다.

명시적인 URL 탭 선택을 데이터 가용성과 분리한다. 장중 탭은 항상 선택할 수
있으며, 선택 시 즉시 재조회한다. 로딩·재시도 가능한 오류·자료 없음·정상
스냅샷을 같은 탭 안에 표시한다. 자동 초기 탭 선택은 기존 장중 조건을 유지한다.
동일 URL 재선택은 방문 기록을 추가하지 않는다. 창이 다시 활성화되거나
네트워크가 복구될 때도 다시 조회한다.

비활성 API에는 `unavailable_reason`과 장중 시간대 여부를 추가한다. 시각을
확인할 수 있으면 마지막 `as_of`와 `trade_date`도 제공한다. 기존 `active`와
스테일 가드는 유지하고, 비활성 응답에는 가격·지수·랭킹을 포함하지 않는다.
클라이언트는 배포 전환 중 기존 `{active: false}` 응답도 처리한다.

이날 09:05·09:15 KRX 지수 조회에서 빈 열 오류가 기록됐고, 09:25 앱 스냅샷은
2,765종목으로 정상 발행됐다. 지연 시세의 초기 부재가 화면 탐색까지 막아서는
안 된다. 수집 주기·자료 유효시간·수집기 운영 설정은 변경하지 않는다.

기존 production build에서 비활성 버튼과 직접 링크의 정산 전환을 재현한다.
API 테스트는 비활성 사유·마지막 관측일·오래된 시세 비노출과 정상 응답을
검사한다. Playwright는 지연 응답, 이전 API 계약, 재시도, 직접 링크·새로고침·
뒤로가기, 갱신 중 비활성 전환, 마감 스냅샷과 390/320px 키보드 동선을 검사한다.
배포 파이프라인도 실제 `/intraday/market` 응답의 가용성 계약을 검사한다.
