# ADR-0016: 원문 중심 Research Feed와 근거가 연결된 읽기 요약

- Date: 2026-09-07
- Status: Accepted for implementation; production acceptance pending
- Supersedes: ADR-0011의 핵심 연구/데이터 업데이트 노출 정책. 과거 기록 검증과 사용자 상태 계약은 유지.

## 결정

연구 피드는 전략 채택 관문이 아니라 사용자가 실제 글을 읽고 인사이트를 얻는 제품이다.
Schema 4는 공식 발행처의 연구 글·논문·프리프린트·연구 다이제스트를 표현한다.
기존 schema 3 issue/changelog는 `updates`, schema 1/2는 기존 보관 기록으로 남긴다.
원문 접근 범위, 저자, 발행일, PDF, 원문 발췌를 표시하며 읽음·저장·검색 기능을 보존한다.

새 자료는 발견함에 먼저 도착한다. 기존 단일 실행 ResearchPoller가 제한된 수의 공개 본문을
GPT-5 nano로 분석한다. 모델의 역할은 주제/내용 분류와
저자의 질문·방법·결론 추출이다. 수익률 검증·전략 추천·임의 점수 산출은 하지 않는다.
모든 구조화 문장은 분석한 본문의 실제 부분 문자열을 근거로 포함해야 한다. 이는 근거
존재 검사이지 의미의 완전한 검증이나 독립 재현이 아니다. 별도 AI 해석 메모도 구분한다.

본문이 충분하고 요약 결과가 퀀트 주제/실질적 내용을 확인한 글만 핵심 연구가 된다.
초록만 접근 가능한 항목과 여러 논문을 모은 다이제스트는 발견함에 남는다. 정책 일반론,
기업 홍보, 소프트웨어 인프라 등은 핵심 연구 알림 대상이 아니다. 요약 대기·실패 중에도
원문은 열 수 있다. 길이가 큰 문서는 분석 문자 범위를 공개하고 전문 분석이라고 부르지 않는다.

## 운영·비용·상태

- EC2/수집 Lambda → S3 원문 기록 → 기존 ResearchPoller → S3 앱 피드 → API/PWA.
  맥북/GPU 워커를 정기 운영 경로에 두지 않는다. 상시 DB·Redis·새 워크플로 서비스는 만들지 않는다.
- 2026-09-07 사용자는 비용을 이유로 Anthropic을 거절했고, 2026-09-08 저가 API 방식을
  승인했다. Research에만 GPT-5 nano와 별도 `OPENAI_API_KEY`를 사용한다. 기존 뉴스의
  Anthropic 설정은 재사용하거나 변경하지 않는다.
- 입력 최대 24,000자, 출력 최대 4,096토큰, 회당 한 편, 문서당 최대 3번 시도,
  30분 재시도 간격, 월 $2의 보수적 요청 예약 상한을 둔다. 호출 전에 최악 비용을
  S3에 예약하며 장애 시 반환하지 않는다. 입력 예약에는 JSON Schema·인코딩과 여유분도
  포함하며 출력 상한/사용량에는 추론 토큰을 포함한다. UTC 월별 이 작업의 요청 상한이지
  OpenAI 계정 전체 청구액·AWS·세금의 상한은 아니다. 상한에 도달해도 수집과 원문 접근은 계속된다.
  키 등록 후 실제 인수 시험도 이 한도에 넣기 위해 운영 $1.90, 격리 시험 $0.10으로 나눈다.
- Responses API는 `store=false`, 도구 없음, strict JSON Schema 출력으로 호출한다.
  모델 응답 형식과 별개로 모든 근거 문장이 실제 입력 본문에 존재하는지 다시 검사한다.
- 문서 digest·파서·제목·모델·프롬프트 버전 캐시. canonical ETag 변경만 재조회한다.
  동일 digest의 분석은 보존하고, 본문 수정은 같은 카드에서 재분석한다.
- 카드 ID와 `available_at` 최초 핵심 노출 시점을 유지한다. 분석 갱신은 읽음·저장·확인 상태를
  변경하지 않는다. 초기 소스 backfill은 핵심이 되더라도 배지/Push를 만들지 않는다.
- 새 알림 후보는 요약 완료까지 outbox에 남는다. 기존 event/subscription 발송 영수증이 재시도를
  중복 제거한다. 요약 API 장애는 이미 준비된 항목의 발송까지 중단하지 않는다.
- 서버 역할은 `app/research_analysis/*`만 추가로 읽고 쓴다. 신규 인프라 서비스는 없다.

Anthropic 시험의 실패 영수증은 이력으로 보존한다. 당시 보수적으로 예약한 금액은
실제 청구액이 아니다. GPT-5 nano의 실제 요약 품질 검증은 아직 완료되지 않았으며,
이 상태를 자동 한국어 요약 또는 운영 릴리스 완료로 보고하지 않는다.
2026-09-08 사용자가 OpenAI 키 등록을 완료했다. 키를 로컬로 꺼내지 않고 Actions의
비배포 시험 모드에서 실제 인수를 진행한다. 경로는 [운영 설정](../runbooks/research-openai-setup.md)에 기록한다.

## 인수 검증

생산자→API projection→요약→알림 회귀, 근거 없는 인용 거절, 비용 예약 선기록, 캐시와
재시도 상한, 본문 변경 후 사용자 상태의 byte 단위 보존, 기존 API/라이브러리 회귀,
프런트엔드 build/lint, 실제 원문과 한국어 요약 20–30편 표본 검사를 완료해야 배포 완료로 본다.
