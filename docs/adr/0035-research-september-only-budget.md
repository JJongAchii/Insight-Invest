# ADR-0035: 2026년 9월 한정 Research 검증 예산

- Date: 2026-09-15
- Status: Accepted
- Supersedes: ADR-0033의 2026년 9월 총액 한도만 변경. 기본 월 분배는 유지.

## 승인과 범위

사용자는 “이번달만 늘리는거야?”라고 확인했고, **9월 총 $5(이미 사용한 금액 포함),
10월부터 기존 월 $2 자동 복귀**라는 설명에 “응”으로 승인했다.
이 승인은 무기한 증액이나 추가 $5 사용 승인이 아니다. 분류·요약 모델, 원문 선별 정책,
수집 소스, 유료 호출 횟수·재시도 정책은 변경하지 않는다.

## 결정

| 적용 기간 (KST) | 운영 | 격리 검증 | 합계 |
|---|---:|---:|---:|
| 2026년 9월 예외 | $1.00 | $4.00 | $5.00 |
| 2026-10-01 00:00 이후 기본 | $0.90 | $1.10 | $2.00 |

1. 기존 `RADAR_ANALYSIS_MONTHLY_BUDGET_USD`는 $0.90/$1.10으로 유지한다.
   선택적인 월/금액 환경변수 쌍으로 2026-09 예외를 명시하고, 공용 예산 함수가
   한국시간의 **연-월**을 비교한다. 이후 9월에 반복 적용되지 않는다.
2. 만료에 운영자·맥북·별도 스케줄러가 필요 없다. 누락된 날짜, 잘못된 월,
   비정상 금액은 유료 호출 전에 실패한다. 기본 한도 0은 예외보다 우선하는 중단 스위치다.
3. UTC `budget-YYYY-MM.json`, 현재 사용액, 실패 예약, 캐시, 사용자 상태를 유지한다.
   예외는 원장의 잔액을 늘리거나 재작성하지 않고 새 요청의 **총 예약 한도**만 바꾼다.
4. 10월 1일 00:00–09:00 KST는 여전히 9월 UTC 원장이므로 기본 한도 초과 시
   새 유료 분석이 일시 중단된다. 09:00 KST에 정상적으로 10월 UTC 원장이 시작된다.
   9월 예외를 10월 오전까지 연장하는 대신 안전하게 중단하는 선택이다.
5. 검증 workflow는 운영 기본/예외 설정을 읽어 확인한다. 검증 코드도 기본 $1.10,
   2026-09 예외 $4를 넘기는 설정을 거절한다. API 서빙 함수에는 키·예산 설정을 넣지 않는다.

## 검증

- 오프라인 날짜 경계: 9월 시작/종료 KST, 10월 UTC 시작, 다음 해 9월.
- 기존 사용액에 비용이 누적되고 만료 후 원장·실패 예약이 초기화되지 않음.
- 유효하지 않거나 승인되지 않은 예외를 API/저장소 접근 전에 거절.
- CloudFormation 운영 $1 + Actions 검증 $4 = $5; 기본 $0.90 + $1.10 = $2.
- 배포 후 실제 Lambda의 비밀이 아닌 예산 필드와 원장 잔액을 확인.

이 한도는 해당 Research 파이프라인의 보수적 비용 예약 한도다. 실제 OpenAI 계정 전체
청구액, 다른 서비스나 AWS 비용의 상한이 아니다. 검증을 위해 새 유료 모델 호출은 필요 없다.
