# ADR-0036: 뉴스는 ai-company 편집 발행본 하나만 읽는다

- 날짜: 2026-11-27
- 상태: 구현 완료, 운영 반영 전
- 대체: ADR-0013 결정 6(경제 뉴스 기본 제공과 경제 RSS 폴백),
  `docs/superpowers/specs/2026-08-14-kr-news-briefing-design.md`
- 요청: "경제 뉴스 브리핑은 없애고 기존 ai-company에서 전달하던 뉴스만 insight-invest에 전달하자.
  Slack 발송도 중단하고, '속보 피드'는 속보가 아닌 뉴스에 맞는 이름으로. 앞으로는 insight-invest에서만
  뉴스를 받아보려고 한다."

## 문제

뉴스가 네 곳에 있었다. 홈의 `경제 뉴스 브리핑`(Google News RSS 규칙 랭킹), 홈의 `최근 속보` 한 줄과
`기업 공시·주요 뉴스`, `/feed`의 `속보 피드`, 텔레그램 시황 보고의 뉴스 톱3. 앞의 하나와 마지막은
RSS 제목 목록이고 나머지는 ai-company 편집기가 원문을 대조해 쓴 글이라 품질과 출처가 달랐다. 편집기
뉴스는 Slack에 전달된 뒤에야 앱에 실렸고, 앱은 그 글을 채팅 서식 본문 그대로 보여줬다.

## 결정

1. 뉴스 소스는 `app/market_desk/board.json` 하나다. Google News RSS 수집(API `/news`·`/news/briefing`,
   시간별 폴러, EC2 `build_news.py`, 텔레그램 톱3, Anthropic 키 파라미터)을 제거한다.
2. 뉴스 화면은 `주요 뉴스`(`/news`) 하나다. Reporter 뉴스, 기업 공시, 정책 발표 해설을 한 목록에 날짜별로
   둔다. 지수·업종 변동 해설은 뉴스가 아니라 시장 해설에 남는다. `/feed`는 `/news`로 넘긴다.
3. 서버가 글을 기사 형태로 정규화한다(`module/desk_news.py`). 발행본이 분야·긴급 여부·핵심 사실·왜
   중요한지를 필드로 주면 그대로 쓰고, 채팅 서식 본문만 있으면 같은 필드로 읽는다. 읽지 못한 본문은
   고치지 않고 그대로 보여준다. 발행본에 일주일 목록(`news`)이 있으면 그것을, 없으면 홈 목록(`issues`)을
   쓰므로 ai-company와 배포 순서가 엇갈려도 동작한다. 뉴스 목록은 형식이 틀린 글 한 건을 빼고 나머지를
   보여주며, 브리핑이나 시장 해설 쪽 형식 오류에 함께 멈추지 않는다.
4. 홈은 최신 5건을 같은 형식으로 미리 보여주고 `최근 속보` 한 줄, `기업 공시·주요 뉴스`,
   `경제 뉴스 브리핑`을 대신한다. 미리보기는 본 것으로 기록하지 않는다.
5. 뉴스 화면을 열면 가장 최신 글의 발행 시각까지 본 것으로 기록한다(`market_desk/news_seen.json`, 기기
   간 공유, 뒤로 가지 않고 현재 시각을 넘지 않음). 그 뒤 발행된 글 수를 사이드바와 모바일 하단 탐색에
   표시한다.
6. 알림은 편집기가 긴급으로 분류한 뉴스만 보낸다. 2분마다 발행본을 읽고, 기기마다 한 번, 발행 후 3시간
   이내 글만 보낸다. 긴급 사건의 후속 발행은 다시 알린다. 나머지 뉴스는 미확인 표시로만 알린다.

## 화면

기존 토큰과 홈 데스크 목록의 형식을 따른다. 시각 열 옆에 분야·제목·첫 문장을 두어 펼치지 않고 훑을 수
있게 하고, 펼치면 핵심 사실, `왜 중요한가`, `달라진 점`, 근거 원문과 출처 이용 조건을 보여준다. 긴급 글은
표식과 왼쪽 선으로 구분한다. 좁은 화면에서는 시각과 분야를 한 줄에 두고 제목이 전체 폭을 쓴다.

## 사용자 확인 없이 정한 것

요청은 화면 구성과 내용을 맡겼다. 아래는 구현자가 정했고 바꿀 수 있다.

- 이름 `주요 뉴스`, 주소 `/news`, 홈 미리보기 5건, 분야 묶음(경제·금융 / 산업·기술 / 무역·에너지 / 세계 /
  기업 공시).
- 알림 범위를 긴급 뉴스로 제한한 것. Slack은 모든 글에 알림이 왔다.
- 아침·마감 브리핑의 Slack 발송은 그대로 둔 것. 영상·뉴스레터 작업이 그 스레드에 이어진다.

## 잃는 것

- RSS 브리핑의 `종합` 탭(국내 정치·사회 주요 기사)은 편집기의 취재 범위 밖이라 사라진다.
- Slack 뉴스 스레드에서 Reporter에게 후속 질문을 하던 경로와 06시 밤사이 묶음 글이 없어진다.

## 검증과 한계

서버는 `pytest`, 화면은 로컬 빌드에 합성 응답을 넣은 `npm run test:market-experience`로 확인한다. 이는
운영 발행본의 내용이나 실제 기기의 알림 도착을 검증한 결과가 아니다. 배포 워크플로가 운영에서 뉴스
목록 조회, 확인 표식 쓰기 권한, 알림 폴러 실행을 확인한다.
