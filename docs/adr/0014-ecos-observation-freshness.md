# ADR-0014: 경제 지표의 실제 관측일과 캐시 만료

Date: 2026-09-07
Status: accepted

한국 일간 경제 지표는 차트 크기를 줄이기 위해 주간 마지막 값으로 집계한다.
기존 API의 `data[].date`는 금요일 집계 라벨이다. 홈과 한국 경제 화면이 이 날짜를
최신 기준일로 사용해 9월 2~3일 관측을 9월 4일 기준으로 표시했다.
운영 S3 수집도 지연됐으며 프로세스 수명 캐시는 갱신 후 추가 지연을 만들 수 있었다.

## 결정

- `/regime/kr` 각 시리즈에 `as_of`, `frequency`, `source`를 추가한다.
  일간은 원본의 마지막 유효 관측일 `YYYY-MM-DD`, 월간 CPI·CLI는 `YYYY-MM`이다.
- 차트용 집계 날짜와 최신 스냅샷을 분리한다. 홈의 숫자는 `latest`, 날짜는 `as_of`를
  사용한다. 구 API 응답에 메타데이터가 없으면 기준일 미확인으로 표시한다.
- ECOS·OECD 원본 캐시는 기존 자산 마스터와 같은 5분 time-bucket 방식으로 만료한다.
  갱신 실패를 지난 값으로 조용히 대체하지 않는다. 차트·국면 계산 방법은 바꾸지 않는다.
- 홈과 한국 경제 화면은 5분 주기로 다시 조회하며, 재진입·포커스·연결 복구에도 갱신한다.
  서버 캐시와 브라우저 조회 간격이 겹치면 S3 발행부터 자동 화면 갱신까지 최대 약 10분이다.
- 앞선 UI 수정에서 잘못 붙인 미국 CPI 지수 수준 라벨도 바로잡는다. 기존 API가 주는
  전년동월 대비 소수 수익률을 프런트에서 100배 해 %로 표시하고 2% 기준선을 복구한다.

## 검증

수요일·목요일 실제 관측과 금요일 집계 라벨이 다른 합성 사례, 월간 기준월,
5분 후 재조회와 갱신 오류 전파를 Python 테스트로 검증한다. 데스크톱·모바일
브라우저 검증에는 같은 날짜 불일치 사례와 미국 CPI 0.021 → 2.10% 표시를 포함한다.
운영 검증은 테스트 fixture와 구분하여 실제 ECOS 원본·S3·배포 API를 대조한다.
