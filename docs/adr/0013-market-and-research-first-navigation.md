# ADR-0013: 시장·경제·리서치를 주 탐색 구조로 배치

- 날짜: 2026-09-07
- 상태: 구현 완료, 운영 반영 전
- 요청: 시장 현황과 분석, 경제 현황, 리서치 문서에서 인사이트를 얻는 것을 최우선으로 두고 개인 판단·포트폴리오는 보조 기능으로 유지한다.

## 문제

기존 홈은 `DecisionBrief → PortfolioCard → 관심 자산·뉴스`로 시작했다. 지수·수급은 접힌 시장 도구에, 리서치 영역은 문헌 대신 신호 후보와 저장 전략에 연결되어 있었다. 주요 메뉴에서도 검토와 포트폴리오가 경제 지표보다 앞섰다. 정보의 우선순위가 사용자가 실제로 원하는 시장 관찰·리서치 탐색과 달랐다.

시장 상세는 모든 분석을 세로로 나열했고 `?tab=intraday`를 읽지 않았다. 경제 지표는 국면·역사적 성과 다음에 있었다. 뉴스 기본 분류는 종합이었으며 제목이 한 줄로 잘렸다. 리서치 발췌는 `title` 속성에 있어 터치 화면과 키보드로 읽기 어려웠다.

## 결정

1. 데스크톱 주 탐색을 시장 브리핑, 한국 시장, 경제·매크로, 리서치, 종목 탐색, 실적 일정으로 구성한다. 모바일 하단은 앞의 다섯 목적지를 공유한다. 개인 도구는 별도 접기 영역과 기존 경로로 제공한다.
2. 홈은 주요 관측값 → 시간축별 시장 흐름 → 경제 뉴스와 최신 문헌 → 수급 탐색 순서로 제공한다. 실제 Research Radar 피드를 홈에서 미리 볼 수 있다. 미리보기는 읽음·보관·미확인 상태를 변경하지 않는다.
3. 장중·전술·구조의 시간축 구분은 유지한다. 데스크톱은 근거를 나란히 비교하고, 모바일은 요약을 먼저 보여주고 관측 근거를 펼친다. 추가 근거와 엇갈림 전체를 읽을 수 있다.
4. 시세의 기준일과 정산/지연 스냅샷 구분을 표시한다. 더 오래된 장중 자료를 정산값 위에 덮지 않으며, 같은 거래일의 마감 스냅샷보다 정산값을 우선한다. 요약 생성 시각은 관측 기준일과 구분한다. 상태표가 비어 있으면 미확인으로 표시한다.
5. 한국 시장은 분석 항목을 선택해서 본다. 선택한 시점·분석 항목·시장 구분을 URL에 보존한다. 국면 페이지는 경제 지표를 기본으로 보여주며 국가와 분석 보기를 URL에 보존한다. 국면·위험과 역사적 성과는 별도로 접근한다.
6. 경제 뉴스를 기본으로 제공하고 제목·맥락을 줄바꿈한다. 선별 뉴스가 없거나 요청에 실패하면 경제 RSS를 제공하며 실패 상태를 표시한다. 리서치 원문 발췌는 실제 펼치기 컨트롤로 제공한다.
7. 수집원·백엔드 계산·리서치 등급·개인 기록 저장 계약은 변경하지 않는다. 거시 차트의 표시 단위와 관측일을 보완하고 CPI 지수 수준에 붙었던 0.02 기준선을 제거한다.

## 시각 설계

관측값과 근거를 비교하는 시장 관찰 화면으로 설계했다. 기존 로고와 테마를 유지하고 새로운 장식 요소를 늘리지 않는다.

- 색: canvas navy `#0a0f1a`, panel navy `#101726`, reading white `#e8ecf4`, steel `#9aa6b8`, lavender `#9b7eff`, sky `#38bdf8`. 상승·하락·경고와 라이트 모드는 기존 의미 토큰을 따른다.
- 글꼴: 홈 제목은 Apple SD Gothic Neo / Inter의 굵은 한글 제목, 본문은 기존 Inter와 시스템 한글 폴백, 수치는 SF Mono 계열의 고정폭 숫자.
- 배치: 짧은 제목과 분석 경로, 네 개 관측값의 연속된 띠, 세 시간축의 비교 영역, 뉴스·문헌의 두 열.
- 대표 요소: 서로 다른 관측 주기를 직접 비교하는 시간축 영역. 색은 시간축 식별에만 보조적으로 쓰고 상태는 텍스트로도 표시한다.
- 화면 확인 후 모바일의 긴 근거 목록을 접기 방식으로 보완했다. 요약은 계속 보이고 키보드·터치로 근거를 열 수 있다.

## 검증과 한계

`npm run lint`, `npx tsc --noEmit`, `npm run build`, `npm run test:pull-refresh`, `npm run test:market-experience`로 검증한다. 브라우저 검증은 로컬 인증과 합성 응답을 사용한다. 생산 데이터의 수집 정상 여부나 투자 분석의 타당성을 검증한 결과로 해석하지 않는다.

홈의 글로벌 자산 영역은 기존 TradingView 위젯을 유지한다. 독자적인 글로벌 시계열 분석, 경제 이벤트 캘린더, 테마별 리서치 연결은 별도 데이터·서비스 설계가 필요하다. 후속 우선순위는 [개선 검토](../reviews/2026-09-07-market-research.md)에 기록한다.
