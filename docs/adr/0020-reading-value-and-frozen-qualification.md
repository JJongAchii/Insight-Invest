# ADR-0020: 원문 읽기 가치와 고정 표본으로 요약을 인수한다

- Date: 2026-09-10
- Status: 구현·실제 인수 중. 자동 요약/핵심 알림은 비활성 유지.
- Approval: 사용자의 "그래 이 개선사항도 참고해서 아무튼 이어서 진행할것들 진행해줘"
- 기존 qws intent `2d79bae58179` 범위이며 전략 구현·재현·성과 채택을 포함하지 않는다.

## 결정

1. 핵심 기준은 논문 형식·기관 이름이 아니라 구체적인 신호·포트폴리오 원칙·시장 메커니즘·
   방법론적 함정을 배울 수 있는가다. 짧은 글이나 실질적인 인터뷰도 허용한다. 시장 전망과
   현재 포지셔닝, 산업 정책, 기관 소식과 개발 도구는 주제와 읽기 목적을 구분한다.
2. `content_kind`의 기존 계약을 유지한다. 핵심 승격에는 검수 통과한 관련성/실질성과
   근거가 붙은 `why_read`도 필요하다. 없으면 발견함에 원문을 보존한다. 재현 가능성,
   인용 수, 학술 심사 여부를 읽기 피드의 필수 조건으로 강제하지 않는다.
3. 생성 v8은 인용 ID를 먼저 고르고 하나의 구체적인 통찰을 간결하게 옮긴다. 조건이 다른
   여러 주장을 한 문장으로 압축하지 않는다. 모르는 용어는 잘못된 한국어 대신 영어를
   유지한다. 검수 v3는 초안 표현을 따라 설명하지 않고 원문 의미와 초안 차이를 대조한다.
   스키마·인용 검사 통과는 의미 정확성을 보장하지 않으므로 실제 응답으로 검증한다.
4. GPT-5 mini/medium, 출력 8192, 입력 24000자, 기존 재시도와 월 시험 $0.50/운영 $1.50
   경계를 유지한다. OpenAI 키를 꺼내지 않고 기존 Actions `research-qualify`만 사용한다.
   9월 기존 예약 $0.19271570을 보존하며 모델 변경이나 한도 초기화는 하지 않는다.
5. 최신 글이 바뀌어 시험이 쉬워지는 문제를 막기 위해 공개 metadata·본문 digest를 고정한다.
   `reading-value-v1`: AQR Warming / RAFI NLP / Robeco credit interview.
   `v7-regression`: 기존 AQR/Robeco/CFM 초안과 입력. 선택한 source별 하나, 최대 3편이다.
   새 검색은 하지 않고 정확한 URL에서 파싱 후 digest를 대조하며 원문이 바뀌면 중단한다.
   검수 기준/예상 분류는 결과 보고에만 쓰며 모델 입력에 넣지 않는다.
6. v7 회귀는 기존 생성 캐시의 fingerprint와 초안 digest를 먼저 확인한다. 없거나 다르면
   중단하고 새 생성으로 대체하지 않는다. v8 생성과 v7 오류 탐지 성능을 따로 보고한다.
   API 연결, 모델의 분류/검수 결과, 사람이 원문을 읽은 의미 판단도 각각 구분한다.
7. 소비자는 quant-data ADR-0025의 최초 발견 증명을 추가 확인한다. 이력이 없는 기존
   pending은 삭제하지 않고 격리 집계한다. 핵심 읽기 자료로 노출되는 것과 새 알림은 별개다.

## 인수와 제한

단위 테스트로 프롬프트 문구 존재만 확인하고 정확성이 높아졌다고 하지 않는다. 기존 오류
표본의 실제 검수, 새 요약의 원문 대조, 좋은 글/시장 배경 양쪽의 분류를 확인한다.
이 3편은 개발 회귀 표본이지 20–30편 다양성 인수를 대체하는 holdout이 아니다.
운영 요약/알림을 켜기 전 해당 인수와 사용자 상태 보존·신규/역사 replay 검사가 필요하다.

[구조화 출력도 의미 오류가 가능함](https://developers.openai.com/api/docs/guides/structured-outputs).
