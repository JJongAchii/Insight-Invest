# Insight Invest 시장·경제·리서치 중심 개선 검토

2026-09-07. 사용자의 우선순위를 기준으로 화면과 코드를 재검토하고 프런트엔드에 반영했다. 운영 배포는 포함하지 않았다.

## 제품이 먼저 답해야 할 질문

1. 시장에서 무엇이 움직였는가? 가격, 참여 종목, 자금 흐름을 같이 본다.
2. 그 움직임의 배경은 무엇인가? 금리·물가·고용·환율과 경기 국면을 확인한다.
3. 무엇을 더 읽어야 하는가? 관련 경제 뉴스, 연구 요약과 원문 근거로 이어진다.
4. 이 관측은 언제의 자료인가? 관측일, 갱신 상태, 발표 주기와 단위를 확인한다.

개인 판단 기록과 포트폴리오는 이 과정을 마친 뒤 필요할 때 쓰는 도구다. 홈을 개인 할 일 목록으로 구성할 필요는 낮다.

## 이번에 반영한 개선

| 영역 | 확인한 불편 | 변경한 경험 |
| --- | --- | --- |
| 주 탐색 | 검토·포트폴리오가 경제보다 우선됨 | 브리핑·한국 시장·경제·리서치·종목을 주요 목적지로 배치. 데스크톱에는 실적 일정도 직접 노출 |
| 홈 | 시장 지수·수급이 접혀 있고 문헌 미리보기가 없음 | 지수·환율·금리, 시간축별 시장 근거, 경제 뉴스, 최신 리서치를 기본 노출 |
| 관측 기준 | 시각만 있는 장중 표시와 생성 시각으로 최신성을 오해할 여지 | 전체 관측일, 정산/지연 구분, 빈 상태표의 미확인 표시. 오래된 스냅샷의 덮어쓰기 방지 |
| 시장 근거 | 추가 근거 개수만 표시, 엇갈림 첫 항목만 표시 | 모든 근거와 엇갈림을 열람. 해당 분석 항목으로 이동 |
| 모바일 홈 | 근거가 길게 쌓여 읽을거리까지 멀어짐 | 시간축별 요약을 유지하고 근거를 펼치도록 조정. 뉴스·리서치 바로가기 제공 |
| 뉴스 | 종합 뉴스가 기본, 긴 제목 잘림 | 경제·시장을 기본으로 표시. 제목과 맥락을 줄바꿈하고 경제 RSS 대체 경로 제공 |
| 리서치 | 별도 메뉴에 진입해야 자료 존재를 알 수 있음 | 홈에서 핵심/발견 자료 요약, 출처, 날짜, 주제를 확인하고 선택 문서로 이동 |
| 리서치 발췌 | 마우스 호버에 의존 | 방법·데이터·검증·결과 발췌를 펼쳐 읽기. 터치·키보드 접근 지원 |
| 수급 | 홈에서는 외국인·1주·순매수만 가능 | 투자자, 기간, 순매수/순매도 선택. 상세 수급 화면과 종목 탐색으로 연결 |
| 한국 시장 | 여러 분석이 한 긴 페이지에 섞임 | 지수·시장폭 / 수급 / 섹터 / 팩터 / 밸류에이션 / 신호를 선택. URL·새로고침·뒤로가기에 선택 보존 |
| 경제 화면 | 실제 지표가 국면·성과 아래에 배치 | 미국·한국 경제 지표를 기본 제공하고 국면·위험을 별도 보기로 구성 |
| 지표 읽기 | 영문 명칭·단위·기준일이 불균일 | 주요 미국 지표의 한글 이름, 금리차 단위, 개별 관측일 보완. 관측값 없는 침체 지표를 비침체로 표시하던 문제 수정 |

로고, 다크/라이트 테마, 주요 개인 기능 경로는 유지한다. 개인 상세 카드는 홈 하단에서 필요할 때 펼친다. 리서치 미리보기로 읽음이나 보관 상태를 바꾸지 않는다.

## 다음 개선의 우선순위

### 1. 글로벌 시장을 같은 기준으로 비교 — 높음

현재 자체 분석은 한국 시장 중심이고 글로벌 영역은 외부 시세 위젯에 의존한다. 미국 주가지수·미 국채 금리·달러·원자재·크레딧을 한 화면에서 같은 기간으로 비교할 수 있어야 거시 변화가 보인다.

- 1일/1주/1개월 변화와 기간 차트, 단위, 거래소별 기준 시각을 제공한다.
- 가격 변화와 금리의 %p 변화는 구분한다. 휴장일과 시차를 숨기지 않는다.
- 실현 조건: 기존 데이터의 커버리지 확인과 추가 공급원 계약. 현재 위젯을 실제 통합 분석 데이터로 간주하면 안 된다.

### 2. 경제 발표 캘린더 — 높음

기존 실적 일정은 기업 발표를 다룬다. CPI, 고용, FOMC, 한국은행, 성장률 등 경제 이벤트를 따로 보면 “왜 오늘 움직였는가”와 “다음에 무엇을 확인할 것인가”가 연결된다.

- 발표 시각, 이전 값, 예상치, 실제 값과 원문 링크를 한 줄로 제공한다.
- 발표 전에는 확인할 지표를, 발표 후에는 무엇이 달라졌는지를 보여준다.
- 실현 조건: 공식 발표 일정과 예상치의 출처, 수정치·잠정치 처리. 확인되지 않은 예상치를 만들어 채우지 않는다.

### 3. 문헌을 시장 주제와 연결 — 높음

현재 피드는 퀀트 연구·방법론 자료에 무게가 있다. 사용자가 원하는 경제·시장 인사이트를 넓히려면 매크로·산업·정책 자료의 범위와 탐색 축이 필요하다.

- “미국 금리”, “한국 수출”, “반도체”, “유동성”처럼 지표·뉴스·논문을 같은 주제로 연결한다.
- 출처/읽음 상태 외에 주제와 문서 종류로 좁힌다. 기관 리포트·정책 원문·학술 연구의 성격을 구분한다.
- 요약에는 질문, 사용 데이터, 관측 결과, 한계, 원문 위치가 드러나게 한다.
- 실현 조건: 출처 확대와 문서 분류·추출 근거. 품질 분류를 투자 아이디어의 성과 보증처럼 표현하지 않는다.

### 4. “무엇이 달라졌는가”를 기준점과 함께 제공 — 높음

최신 수준만으로는 변화를 놓치기 쉽다. 지수는 전 거래일, 월간 경제 지표는 직전 발표, 문헌은 새 문서·수정 문서를 기준으로 비교해야 한다.

- 비교 기준을 명시하고 이전 값 → 현재 값 → 변화의 배경 자료를 제공한다.
- “지난 방문 이후”와 “전일 대비”를 별도 의미로 관리한다.
- 실현 조건: 관측·발표·수정 시점이 보존된 이력. 현재의 변화 감지 플래그만으로 모든 비교를 표현할 수는 없다.

### 5. 자주 보는 분석을 다시 여는 편의성 — 중간

종목·시장·문헌 검색 조건을 저장하거나 URL로 다시 열 수 있게 한다. 개인화의 중심은 자산 보유 목록보다 사용자가 관찰하는 시장과 주제에 둔다. 이번에는 시장 분석 보기·시장 구분, 경제 보기·국가, 기존 리서치 링크를 연결했다. 하위 차트 기간과 모든 검색 조건의 보존까지 통일한 것은 아니다.

### 6. 데이터의 빈칸과 지연을 읽을 수 있게 — 중간

지표별 관측일 표시는 이번에 보완했다. 후속으로 예상 갱신 주기, 실제 발표일, 수정 가능성, 대상 종목 커버리지를 같은 규칙으로 설명할 필요가 있다. 데이터가 없는 화면을 정상이나 0으로 읽게 하는 다른 경로도 차례로 정리한다.

### 7. 실제 사용 기준으로 성능과 정보량을 조정 — 중간

큰 요약 API의 응답을 기다리는 동안 다른 정보를 읽을 수 있어야 한다. 이번 홈은 영역별로 표시하고 시장 상세는 선택된 분석만 렌더링한다. 후속 작업에서는 운영 API의 응답 시간·실패율을 측정하고, 공통 레이아웃의 개인 알림 조회도 방문 목적에 맞춰 조정할 수 있다. 이번 작업으로 운영 로딩 시간이 몇 초 단축됐다는 수치는 측정하지 않았다.

## 검증

- 정적 검사: 린트, TypeScript, Next.js 16.3.1 프로덕션 빌드.
- 기존 회귀 검사: pull-to-refresh 5개.
- 브라우저 검사: 11개 시나리오. 홈 우선순위, 기준일, 데이터 미확인, 수급 선택, 리서치 이동·발췌·상태 보존, 장중 링크, 시장 URL/뒤로가기, 경제 국가 선택, 모바일/테마, 오래된 스냅샷, 빈 데이터·실패 대체 경로.
- 뷰포트: 데스크톱 1440px, 모바일 390px 및 320px. 다크·라이트 화면과 키보드 펼치기 확인.
- 브라우저 응답은 **합성 테스트 자료**다. 화면 속 숫자·뉴스·연구는 실제 시장 데이터나 성과가 아니다. 운영 API·iOS Safari 실기기·외부 TradingView 공급 상태는 이 검사로 보증하지 않는다.

### 재실행

`client`에서 `npm ci` 후 Chrome이 설치된 환경에서 실행한다. 다음 코드는 로컬 검사 전용 서버를 띄운다. 실제 접근 코드나 운영 API 설정은 사용하지 않는다.

```bash
SITE_ACCESS_HASH=$(node -e "process.stdout.write(require('node:crypto').createHash('sha256').update('insight-local-ui-review').digest('hex'))") npm run dev -- --hostname 127.0.0.1 --port 3107
```

다른 터미널의 `client`에서 `npm run test:market-experience`를 실행한다. 기본 결과 경로는 `/tmp/insight-market-research-review`다. `UI_BASE_URL`, `UI_BROWSER_CHANNEL`, `UI_OUTPUT_DIR`로 로컬 주소·설치된 브라우저 채널·출력 경로를 지정할 수 있다.
