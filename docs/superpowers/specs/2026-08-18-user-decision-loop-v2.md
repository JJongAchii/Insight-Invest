# 사용자 의사결정 루프 v2

- 작성일: 2026-08-18
- 대상: Insight-Invest 웹, API, 사용자 저장소, quant-data 일일 수집
- 목표: 정보 나열 화면을 `변화 감지 → 해석 → 내 자산 영향 → 판단 기록 → 사후 검토` 흐름으로 바꾼다.

## 제품 원칙

1. 하나의 종합 점수로 서로 다른 시간축을 섞지 않는다. 장중, 전술(1~4주), 구조적
   (3~12개월) 근거를 분리하고, 불일치는 결론이 아니라 충돌로 보여준다.
2. 값에는 통화, 관측일, 계산일, 데이터 상태를 붙인다. 한국 시가총액과 가격은 KRW,
   미국은 USD로 표시하며 시장별 필터 기준을 교차 적용하지 않는다.
3. 사용자의 보유·관심 자산과 연결되지 않은 일반 정보보다, 지난 방문 뒤 바뀐 근거와
   임계치를 넘은 예외를 먼저 보여준다.
4. 저널은 자유 메모가 아니다. 관찰, 해석, 결정, 시간축, 확신도, 반증, 무효화 조건,
   검토일과 당시 데이터 스냅샷을 함께 저장한다.
5. 거래와 현금 흐름은 수정 가능한 현재 상태가 아니라 불변 이벤트로 기록한다. 보유량,
   실현·미실현 손익, TWR은 원장에서 파생하며 계산 불가능한 항목은 추정하지 않는다.
6. 백테스트·최적화 화면은 Research Lab으로 격리한다. 커버리지, PIT 한계, 비용, 통화,
   벤치마크를 확인하기 전 결과를 투자 근거처럼 표현하지 않는다.

## 구현 순서와 수용 조건

### 1. 탐색과 표현 정확성

- 모바일 첫 진입에서 사이드바가 본문을 가리지 않고, 열었을 때 배경막·링크 이동·Esc로
  닫힌다. 주요 페이지는 하단 내비게이션으로 접근할 수 있다.
- 종목 검색의 스파크라인 요청은 현재 페이지 종목만 포함한다.
- KR/US 가격·시가총액·날짜가 시장과 로케일에 맞게 표시된다.
- 행은 키보드 Enter/Space로 열 수 있고 아이콘 버튼에 접근 가능한 이름이 있다.

### 2. 홈 판단 구조

- 홈의 첫 화면은 지난 방문 변화, 내 자산 예외, 시간축별 환경 순서다.
- 구조적 환경은 경기 국면·밸류에이션, 전술 환경은 시장 위험도·시장폭·5일 수급,
  장중 환경은 실제 장중 데이터 가용 여부를 사용한다.
- 전체 방향은 모든 시간축이 일치할 때만 표시하고, 아니면 `시간축별 혼조`로 남긴다.
- 같은 위험도·국면 설명은 한 번만 보여주고 상세 차트는 접어서 아래에 둔다.

### 3. 개인 판단 기록

- 관심종목에 논거, 촉매, 반증/무효화 조건, 검토일을 저장·수정할 수 있다.
- 저널 엔트리는 작성 당시 overview와 data-status 스냅샷을 서버에서 캡처한다.
- 지난 방문 카드는 브라우저별 이전 방문 시각과 현재 데이터의 변경점을 구분한다.
- 뉴스 관련성은 결정론적 종목/섹터/거시 키워드 매핑으로만 표시하며 감성 매매 신호로
  표현하지 않는다.

### 4. 포트폴리오 원장

- 첫 사용자는 수동 입력, CSV 예시 내려받기/가져오기, 샘플 둘러보기의 차이를 안다.
- 거래·배당·수수료·입출금·환전 이벤트는 append-only ID와 발생시각을 가진다.
- 원장 기반 파생값만 실현/미실현 손익과 TWR로 표시한다. 가격·FX 커버리지 부족 시
  해당 기간/종목과 제외 이유를 함께 표시한다.
- 종목별 투자 논거, 무효화 조건, 다음 검토일을 포지션과 연결한다.

### 5. 데이터 신뢰와 Research Lab

- 레짐 차트는 CLI와 CPI를 별도 축/패널로 보이고 전환 배경을 월별 띠로 도배하지 않는다.
- `Risk-Off Gauge`는 `시장 위험도`로 바꾸며 낮음/중립/높음으로 표현한다. 구성요소의
  관측값과 점수 산식 신호를 분리한다.
- 데이터 신뢰센터는 소스별 마지막 성공, 시장일 기준 신선도, 행 수, 제외/부분 상태,
  빌드 버전을 보여준다. size factor 결측은 `정상`으로 숨기지 않는다.
- Research Lab은 기본 접힘이며 저장 전략의 상태, 데이터 기간, 벤치마크, 통화, 비용,
  감사 여부를 명시한다. 감사 없는 결과는 `연구용·미검증`이다.

### 6. 일일 가격 운영

- 09:00 KST 회차는 Massive US raw/clean/app 가격과 상태 sidecar에 집중한다.
- 19:00 KST 회차는 KRX·거시·인사이트를 포함한 전체 파이프라인이다.
- 모드는 환경변수로 명시할 수 있고, 기존 스케줄에서는 KST 실행시각으로 안전하게
  호환한다. 어느 모드든 필수 산출물·상태가 실패하면 성공 종료하지 않는다.

## 데이터 및 연구 한계

- 현재 월별 경기 국면은 발표 시차를 적용하지만 완전한 빈티지 데이터가 아니다.
- SEC 카드는 현재 연간 10-K 기준이며 분기 10-Q를 제공하기 전까지 연간임을 명시한다.
- 뉴스 키워드 관련성은 인과 또는 수익 예측이 아니다.
- 백테스트 실행·성과 비교 로직은 이 변경에서 재보정하지 않는다. UI 가드레일과 실제
  커버리지 검증만 추가하며 성과 수치는 별도 검증 절차 없이 채택하지 않는다.
